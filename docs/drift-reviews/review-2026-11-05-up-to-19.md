### C1. Tracked notes name the operator's other projects and the mail vendor, against the repository's own rule

- **What was decided.** The repository rule set at bootstrap (Session 1, commit `ff0b75a`) and still in
  `CLAUDE.md` (Conventions): "This repository is public. Its notes files describe Ulak and nothing else: no
  hostnames, tokens, ids, or names of the operator's other projects." Session 6 acted on it: the review
  records "memory moved into gitignored `memory/`", and `MEMORY.md` repeats that the clients' names and details
  live only in gitignored files, "still never in a tracked file".
- **Current direction.** The tracked, public `completed_tasks.md` names the operator's other projects and the
  mail vendor throughout: 64 lines match the names of the two clients, the operations project and the vendor
  (`git grep -c` on `HEAD`). The count has grown with each session: 5 lines at the Session 10 wrap-up, 35 before
  the Session 13 commit, 64 now. It also names two further projects (Session 15 entry). Commit `d3a1b8a`
  (Session 17, "no addresses or host names in the public notes (hygiene test)") closed the address and host-name
  half of the rule only; no check covers project names, and the Session 17-19 entries kept adding them.
  Verified: no e-mail address, host name, postal code or token is in the tracked notes; the leak is names only.
  (Code and test files also name the vendor in an authorization-scheme string, which is a protocol constant, not
  a note, and is not counted.)
- **Why they conflict.** The rule says notes describe Ulak and nothing else and lists "names of the operator's
  other projects". The notes now do the opposite, at growing volume, and the guard that was built for the
  sibling half of the rule does not catch it. The previous review did not check this.
- **Question for the owner.** Keep the rule (then the names are removed from the tracked notes, generic wording
  used, and the hygiene test extended to project names), or drop the project-name part of the rule from
  `CLAUDE.md`. History would still hold the names unless he also wants it rewritten.
